# Driving & Vehicle License Department (DVLD)

## Overview

DVLD is a comprehensive desktop management system developed to automate and manage the operations of a Driving & Vehicle License Department.

The system provides an integrated solution for managing people, driving license applications, local and international licenses, tests, and other licensing-related operations through an organized and user-friendly interface.

## Technologies Used

- **Programming Language:** C#
- **Framework:** .NET Framework
- **UI Technology:** Windows Forms
- **Database:** Microsoft SQL Server
- **Data Access:** ADO.NET
- **Architecture:** Three-Tier Architecture

## Architecture

The application follows a Three-Tier Architecture to ensure separation of concerns, maintainability, and code reusability.

- **Presentation Layer:** Handles the user interface and user interactions using Windows Forms.
- **Business Logic Layer:** Contains business rules, validation, and application workflows.
- **Data Access Layer:** Handles database operations and communication with SQL Server using ADO.NET.

## Key Features

- People Management (Add, Update, Delete, and Find).
- Driver Management.
- Driving License Applications Management.
- Local and International Driving Licenses.
- License Renewal and Replacement.
- Driving Tests Management.
- Application Status Tracking.
- User and Login Management.
- Country and Personal Information Management.

## Project Goals

- Apply Object-Oriented Programming (OOP) principles.
- Implement Three-Tier Architecture.
- Practice database design and SQL Server integration.
- Build maintainable and reusable code.
- Develop a real-world desktop management application.
